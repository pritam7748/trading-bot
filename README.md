# BTC 15m Scalping Trading Alert Bot 🚀

বিটকয়েন (BTC/USDT) এর ১৫ মিনিটের (15m) ক্যান্ডেলে স্বয়ংক্রিয়ভাবে আপনার নির্ধারিত ৪টি BUY শর্ত এবং ৪টি SELL এক্সিট সংকেত ট্র্যাক করে তাৎক্ষণিক টেলিগ্রাম অ্যালার্ট পাঠানোর স্বয়ংক্রিয় বট।

---

## 📊 ট্রেডিং শর্তসমূহ (Strategy Rules)

### 🟢 BUY এন্ট্রি শর্ত (৪টি শর্তই একসাথে পূরণ হতে হবে):
1. **EMA 20 > EMA 50**: ছোট সময়ের EMA, বড় সময়ের EMA-এর উপরে থাকবে।
2. **RSI 50–65**: বাজারে পরিমিত বুলিশ মোমেন্টাম থাকবে।
3. **MACD**: MACD Line, Signal Line-এর উপরে থাকবে।
4. **Support Bounce**: দাম Support লেভেল থেকে বাউন্স করে গ্রিন ক্যান্ডেল তৈরি করবে।
*📌 **Candle Close** হওয়ার সাথে সাথে ৪টি শর্ত মিললে Telegram-এ তাৎক্ষণিক BUY অ্যালার্ট পাঠানো হবে।*

---

### 🔴 SELL / Exit সংকেত (যেকোনো একটি ঘটলেই সতর্কতা):
1. **EMA 20 < EMA 50**: EMA 20 নিচে নেমে গেলে।
2. **RSI 70+ Turn Down**: RSI ৭০-এর উপরে গিয়ে নিচের দিকে ঘুরলে।
3. **MACD Cross Down**: MACD Line, Signal Line-এর নিচে চলে গেলে।
4. **Resistance Rejection**: Resistance লেভেল থেকে দাম রিজেক্ট হয়ে রেড ক্যান্ডেল/উইক তৈরি করলে।
*📌 সংকেত পাওয়া মাত্রই Profit Booking বা Stop-Loss ট্রেইল করার রিমাইন্ডার পাঠানো হবে।*

## ⚙️ টেলিগ্রাম বট সেটআপ (মাত্র ২ মিনিট)

### ধাপ ১: Bot Token সংগ্রহ করুন
1. টেলিগ্রাম অ্যাপে গিয়ে সার্চ করুন: `@BotFather`
2. মেসেজ পাঠান: `/newbot`
3. বটের নাম এবং ইউজারনেম দিন (যেমন: `my_btc_alert_bot`)।
4. BotFather আপনাকে একটি **API Token** দেবে (যেমন: `7123456789:AAH...`)।

### ধাপ ২: Chat ID সংগ্রহ করুন
1. টেলিগ্রামে গিয়ে সার্চ করুন: `@userinfobot`
2. `/start` পাঠান, এটি আপনার **Id** (যেমন: `123456789`) প্রদর্শন করবে।
3. আপনার তৈরি করা নতুন বটে গিয়ে একবার `/start` চাপুন।

### ধাপ ৩: `config.json` ফাইলে বসান
`config.json` ফাইলটি ওপেন করে `botToken` এবং `chatId` আপডেট করুন:

```json
{
  "symbol": "BTCUSDT",
  "interval": "15m",
  "telegram": {
    "botToken": "আপনার_টোকেন_এখানে_দিন",
    "chatId": "আপনার_চ্যাট_আইডি_এখানে_দিন"
  }
}
```
